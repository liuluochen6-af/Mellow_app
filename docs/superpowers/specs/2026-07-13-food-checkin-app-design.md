# 吃喝玩乐打卡 App — 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
一款以个人记录 + 游戏化成就为核心的 iOS 打卡 App。用户记录去过的餐厅、咖啡店、景点等地点，通过日历和地图两个维度回顾自己的探索足迹，同时具备轻量社交功能。

### 1.2 目标用户
喜欢探店、旅行、记录生活的个人用户。核心驱动力是"点亮地图"和"回顾足迹"的成就感，社交是辅助而非核心。

### 1.3 平台
iOS（SwiftUI 原生开发），先上 iOS App Store。

---

## 2. 功能模块

### 2.1 打卡模块（核心）

**打卡流程：**
1. 点击 "+" 按钮发起打卡
2. 拍照或从相册选择照片
3. 选择地点（自动定位当前位置 / 搜索店铺名称）
4. 选择评分（夯 / 不错 / 一般 / 拉，4 级）
5. 添加标签（自由输入，系统记住历史标签方便复用）
6. 添加文字备注（可选）
7. 选择是否公开（好友可见）
8. 发布

**打卡记录包含：**
- 照片（1张或多张）
- 地点名称（如"茶酸奶 蓝色港湾店"）
- 地址文本 + 经纬度坐标
- 行政区划（国家/省/市/区）
- 评分（1-4级：拉/一般/不错/夯）
- 自定义标签
- 文字备注
- 时间戳
- 公开/私密设置
- 匿名发布选项
- 消费金额（可选填）


**消费记录：**
- 打卡时可选填消费金额（人均或总消费）
- 在打卡详情和地图图钉弹窗中展示消费参考
- 统计模块中展示：月度/年度消费总额、各类别消费占比

**地点选择：**
- 使用 MapKit MKLocalSearch 搜索附近店铺
- 自动获取当前 GPS 定位
- 自动解析出省/市/区/国家（用于地图填色和统计）

---

### 2.2 日期墙（日历视图）




**月视图：**
- 标准月历格子布局
- 有打卡的日期显示照片缩略图
- 今天日期高亮显示（金色/橙色）
- 下方统计卡片：本月 X 次打卡，X 家店铺
- 下方照片拼贴展示
- 左右滑动切换月份

**年视图：**
- 展示 12 个月的缩略格
- 每个月格子用颜色深浅表示打卡频率（多=深，少=浅）
- 一眼看全年打卡分布
- 点击某月进入月视图
- 左右滑动切换年份

---

### 2.3 地图模块

**区域填色（宏观）：**
- 缩小视角：已打卡区域彩色填充，未打卡区域灰色/透明
- 缩放层级动态切换：世界→国家→省→市→区县
- GeoJSON 边界数据：
  - 世界国家边界：Natural Earth 开源数据
  - 中国省/市/区县边界：阿里 DataV 数据

**图钉标记（微观）：**
- 放大到街道级别后显示具体打卡图钉
- 图钉可点击展开该地点的打卡详情（照片、评分、备注）
- 同一地点多次打卡显示打卡次数

**填色逻辑：**
- 某区域内有 ≥1 次打卡 → 该区域点亮
- 使用 MapKit 的 MKPolygon 覆盖层渲染

---

### 2.4 社交模块

**好友系统：**
- 通过手机号或用户名搜索用户
- 发送/接收好友请求
- 好友列表管理

**好友动态（时间线）：**
- 按时间倒序展示好友的公开打卡记录
- 展示照片、地点、评分、标签

**评论与 @：**
- 在任意打卡记录下发表评论
- 输入 @ 符号弹出好友列表供选择
- 被 @ 的好友收到推送通知

**推送通知触发场景：**
- 被好友 @ 时
- 收到好友请求时
- 好友评论我的打卡时

---

### 2.5 统计模块

- 去过的国家/省/市/区数量
- 总打卡次数
- 每个地方的最佳推荐（评分最高的店铺）
- 月度/年度打卡概览
- 月度/年度消费总额
- 各类别消费占比（餐饮/饮品/娱乐等）
- 单店消费记录和均价

---

### 2.6 用户系统

**登录方式（二选一）：**
- Sign in with Apple（一键登录）
- 手机号 + 短信验证码（阿里云短信服务）

**个人资料：**
- 昵称
- 头像
- 手机号（可选绑定）

## 3. 页面结构

### 3.1 Tab 栏

```
┌────────┬────────┬────────┬────────┐
│  日历   │  地图   │  动态   │  我的   │
└────────┴────────┴────────┴────────┘
```

### 3.2 各 Tab 内容

| Tab | 主要内容 |
|-----|---------|
| 日历 | 日期墙（月视图/年视图切换）+ 月度统计 |
| 地图 | 世界地图 + 区域填色 + 打卡图钉 |
| 动态 | 好友打卡时间线 + 评论 |
| 我的 | 个人资料、好友管理、统计总览、设置 |

### 3.3 打卡入口

底部 Tab 栏中央或导航栏右上角的 "+" 按钮，全局可触达。

## 4. 技术架构

### 4.1 技术栈

| 层 | 技术选型 |
|----|---------|
| iOS 前端 | SwiftUI |
| 本地缓存 | SwiftData |
| 地图 | Apple MapKit + MKPolygon |
| 地点搜索 | MapKit MKLocalSearch |
| 后端框架 | Python FastAPI |
| 数据库 | PostgreSQL + PostGIS（地理查询） |
| 图片存储 | 阿里云服务器硬盘 |
| 推送服务 | APNs (Apple Push Notification) |
| 短信服务 | 阿里云短信 |
| 地图边界数据 | GeoJSON (阿里 DataV + Natural Earth) |
| 服务器 | 阿里云 ECS |

### 4.2 系统架构

```
┌─────────────────────────────────────────┐
│           iOS App (SwiftUI)             │
├─────────────────────────────────────────┤
│  UI 层：日历 / 地图 / 动态 / 我的        │
│  本地缓存：SwiftData（离线可打卡）       │
│  网络层：URLSession → REST API          │
└────────────────┬────────────────────────┘
                 │ HTTPS
┌────────────────▼────────────────────────┐
│       阿里云服务器 (Python FastAPI)       │
├─────────────────────────────────────────┤
│  用户认证 / 打卡记录 / 社交关系 / 推送   │
│  数据库：PostgreSQL + PostGIS           │
│  图片：服务器磁盘 + FastAPI 静态文件     │
└─────────────────────────────────────────┘
```

### 4.3 数据流

- 用户打卡 → 本地 SwiftData 立即保存 → 后台同步到服务器
- 照片 → 原图存手机本地，压缩图上传服务器硬盘
- 好友动态 → 从服务器拉取
- 地图渲染 → 客户端 MapKit + 本地打包的 GeoJSON 数据

## 6. 评分系统

### 6.1 评分等级

| 等级 | 含义 | 数值 |
|------|------|------|
| 夯 🔥 | 超棒，强烈推荐 | 4 |
| 不错 👍 | 值得一去 | 3 |
| 一般 😐 | 没什么特别 | 2 |
| 拉 💩 | 踩雷，不推荐 | 1 |

### 6.2 标签

- 用户自由输入
- 系统记住用户历史使用过的标签，输入时自动补全
- 示例标签：排队久、性价比高、环境好、份量大、适合拍照、约会圣地

## 7. 设计风格

参考用户提供的截图风格：
- 暖色米黄/奶油色背景
- 深棕色文字
- 金色/橙色高亮（今天日期等）
- 圆角卡片式 UI
- 整体温暖、文艺、有质感

## 10. App Store 上架要点

- 需要隐私政策页面（收集位置、照片权限）
- 需要用户协议
- App 有第三方登录时必须提供 Sign in with Apple
- 需要准备 App 截图（6.7寸 + 6.5寸 + 5.5寸）
- 需要 App 图标 1024x1024
- 审核周期通常 1-3 天
